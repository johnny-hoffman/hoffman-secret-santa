# Hoffman-Imperial Secret Santa 🎅🔨

Home Tools Edition, 2026. One self-contained page (`index.html`), no backend.

- **Organizer:** open the site with no `?t=` and tap **Draw Names**. You get one link per person. Text each person only their own.
- **Recipients:** each link shows a "Are you ___?" check, then the construction-site reveal with Charlie & Effie.
- **Privacy:** names are drawn in the browser, and each link's assignment is scrambled. The code holds no secrets.
- `PROMPT.md` is the one-shot prompt this was built from.
